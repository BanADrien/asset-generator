## Exemples du jeu (style/examples/)
Copies reduites d'assets du depot https://github.com/BanADrien/agarica (projet de
l'utilisateur, usage interne) : tuiles dessinees a la main, sprites IA actuels ramenes a leur
taille ecran (`examples.json` donne le fichier source et l'echelle).

## Idees reprises d'autres skills (lus comme donnees, rien installe)
- `with-pebbly/aseprite-ai-artist` (review) : lecture a froid avant le brief, controles
  mecaniques puis visuels, rapport qui dit les compromis.
- `prokstudio/skills` (pixel-art-fundamentals, critique-checklist) : tests silhouette, valeurs,
  1:1, « set test » a cote de 3 assets du projet, table symptome -> correction.
- `scenario-labs/skills` (scenario-quality-gate) : verifier la structure (comptes, pieces
  rattachees) que les notes globales ratent ; une variable a la fois ; s'arreter quand la
  note stagne et livrer le meilleur avec ses defauts.

## Outils
- pixel-fixer (« unslop pixelart », depot BanADrien/pixel-fixer, copie locale de
  l utilisateur, chemin dans `config.local.json` non versionne ; Node + sharp requis).
- AI Horde (https://aihorde.net) : generation communautaire gratuite, cle anonyme publique.
- Pollinations (https://image.pollinations.ai) : secours, sans cle, quota anonyme bas.
